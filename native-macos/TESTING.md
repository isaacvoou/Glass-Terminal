# Проверка Glass Terminal

## Выполнено в Linux

```sh
python3 tests/test_pty.py
python3 tests/test_frontend.py
node --check resources/terminal.js
sh -n build.sh
```

Результат: **8 тестов PTY и 6 тестов интерфейса пройдены**. C собирался GCC с `-std=c11 -Wall -Wextra -Werror -pthread`. Фронтенд выполнялся в Chromium через Playwright с настоящими включёнными в проект библиотеками xterm.js, FitAddon и SearchAddon.

Проверены:

- Управляющий PTY на stdin/stdout/stderr, переменные окружения, рабочая папка с пробелами и код выхода.
- Передача изменённого размера терминала дочернему процессу.
- Вывод 3 МиБ с временно остановленным потребителем: без потери байтов.
- Ввод 1 МиБ бинарных данных: без изменения контрольной суммы.
- Ctrl+C прерывает отдельную программу, оболочка остаётся доступна.
- Русский текст, UTF-8, CJK и emoji; в браузере UTF-8 разделён между пакетами посередине символа.
- Закрытие живого сеанса без зависания, дочерний процесс забран через waitpid.
- Ошибки запуска и некорректные размеры.
- ANSI-цвета, восстановление основного экрана после альтернативного, bracketed paste.
- Поиск и копирование из поля поиска, изменение размеров после изменения шрифта.
- Вывод с HTML-разметкой остаётся текстом; OSC 52 не пишет в буфер обмена.

Тесты фронтенда требуют Python 3, Playwright и установленный Chromium. Для самого приложения они не нужны. HTTP-сервер запускается только тестами на loopback и отсутствует в приложении.

## Что требует проверки на macOS

macOS SDK и среда выполнения AppKit здесь недоступны. Компиляция `src/main.m` и запуск `.app` в этой среде не выполнены. Браузерные тесты Chromium не заменяют проверку WKWebView на Mac.

После `sh build.sh` проверьте на Mac:

1. Открывается окно, оболочка получает ввод, русский текст вводится через обычную раскладку и IME.
2. Фон действительно прозрачный; 0% затемнения отключает размытие. Текст остаётся читаемым, скругления видны на всех четырёх углах, размер и перемещение окна работают.
3. Вкладки работают независимо, Cmd+C/V/F/T/W и команды меню попадают в нужную вкладку. Поиск не отправляет текст оболочке.
4. При изменении размера результат `stty size` меняется. Ctrl+C останавливает `sleep 30` и возвращает приглашение оболочки.
5. Доступные на Mac vim/less/top/ssh/tmux правильно обновляют экран, ввод и мышь.
6. Кнопки закрытия/сворачивания/полного экрана работают; при активной программе появляется подтверждение закрытия.
7. Настройки сохраняются после выхода, нулевой радиус в полном экране восстанавливается при выходе из него.
8. Перетаскивание файлов с пробелами и апострофами вставляет экранированный путь, а не выполняет команду автоматически.

Внутренняя совместимость WebKit с KVC `drawsBackground` отдельно описана в README. В этом проекте она пока не проверена на конкретной версии macOS.
