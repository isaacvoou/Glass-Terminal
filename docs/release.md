# Glass Terminal 0.2.0

A transparent terminal emulator with customizable window appearance, independent tabs, search, clipboard integration, and native shell sessions.

## Downloads

- **Windows 10/11 x64:** `.exe` installer.
- **macOS 13+ Apple Silicon:** `.dmg` and `.zip` desktop packages.
- **macOS 13+ Intel:** `.dmg` and `.zip` desktop packages.
- **Linux x64:** `.deb` and `.AppImage` packages.
- **macOS AppKit edition 0.1.1:** files with `Native` in their names, supplied as `.dmg` and `.pkg` installers for Apple Silicon and Intel.

Use `SHA256SUMS.txt` to verify downloaded files. Node.js and a compiler are not required to run the installed applications.

The Windows installers do not have a trusted publisher signature. The macOS applications use ad-hoc signatures and are not notarized by Apple.
